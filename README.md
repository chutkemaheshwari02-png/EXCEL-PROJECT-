# EXCEL-PROJECT-
Analysis using the EXCEL


THIS DATASET  CONSIST OF FINANCE DOMAIN DATA SET;

FINDING INSIGHTS;

•	The project focuses on individual investment behavior.

•	It helps understand different investment avenues.

•	It analyzes investors based on age, gender and investment preferences. 

•	It studies investment objectives and reasons. 

•	Excel is used to convert raw data into meaningful insights. 


Explanation:
“The main purpose of this project is to understand how people make investment decisions and which investment options they prefer.”
________________________________________




Objectives
1.	Analyze the investor dataset. 
2.	Identify the most preferred investment avenue. 
3.	Analyze investment preferences by gender. 
4.	Study age groups and investment choices. 
5.	Understand investors' savings objectives. 
6.	Analyze monitoring frequency. 
7.	Compare Equity and Mutual Fund preferences. 
8.	Create Pivot Tables and charts. 
9.	Develop an interactive Excel dashboard. 
10.	Generate useful financial insights.
